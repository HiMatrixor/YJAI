一、产品简介

YJAI · AI 阅卷助手 是一款面向教师与阅卷人员的 Windows 桌面软件，用 AI 自动化批改试卷的主观题与客观题，大幅降低阅卷工作量。

  • 🔒 本地运行：阅卷数据与密钥均保存在本机，不经过第三方服务器
  • 💰 一次买断：无订阅、无积分充值、无隐藏费用
  • 🖥️ 多模型兼容：支持 OpenAI / DeepSeek / 通义千问 / 智谱 / Kimi 等主流 AI 服务
  • 🆓 3 天免费试用：浏览器自动化阅卷提供 3 天试用

二、软件安装

  1. 下载安装包 YJAI-Setup-x.x.x.exe
  2. 双击运行，按提示选择安装路径（可选），完成安装
  3. 首次运行时 Windows 可能弹出 SmartScreen 提示（因未做代码签名），点击「仍要运行」即可

三、四大核心功能

1. 🌐 浏览器自动化阅卷（专业版）

接管网页阅卷平台，自动完成「截图 → AI 评分 → 填分 → 提交」全流程，实现无人值守阅卷。

  1. 选择浏览器内核（Chrome / Edge）并输入阅卷平台网址
  2. 框选「题目区域」，再按平台类型配置填分方式
  3. 配置 AI 评分标准（题目、满分、参考答案、得分点）
  4. 选择批阅模式：顶尖（全自动无人值守）/ 稳健（确认后提交）/ 标准（仅评分不填分）
  5. 点击「自动运行」，实时监控进度

填分方式（两种可切换）：

  • 🖱️ 元素拾取（普通网页）：适用于有真实输入框/按钮的平台，点「拾取」后单击页面中对应元素即可
  • 📍 坐标点击 + 连点累加（e卷通等）：适用于学科网 e卷通等 Canvas 渲染、无真实输入框的阅卷平台。点「给分点坐标」后，在页面中单击答题区域内点击可累加分数的位置；软件会按坐标连点累加填分（默认每点 +1 分，可调步长），再点「提交按钮坐标」完成提交
浏览器页面支持独立窗口打开与缩放，方便完整查看被遮挡的内容；缩放后需重新框选与拾取坐标。

2. ✏️ 智能阅卷（单题批改）

针对单道主观题，按评分标准由 AI 精准评分，附扣分理由、评语与改进建议。

填写评分标准（两种方式可切换）：

  • ✍️ 手动输入：直接填写题目、满分、参考答案、得分点
  • 📤 上传试卷文件：上传 .docx / .pdf / .txt / .md，点「AI 解析」自动识别题目、参考答案与得分点填入，可切换题目、手动修改

输入学生答案：

  • 粘贴学生答案（文字或截图），或从剪贴板批量粘贴
  • 学生姓名/考号选填——软件会自动从答案首行或图片中识别姓名考号
  • 点击「AI 评分」，自动给出分数与评语

3. 📝 整卷阅卷（批量批改）

支持整套试卷（多题 × 多学生）一次完成，自动生成总分、排名、平均分、及格率，可导出 Excel / Markdown。

① 试卷信息（两种方式可切换）

  • ✍️ 手动录入题目：逐题填写题目、满分、评分标准
  • 📤 上传试卷文件：上传 .docx / .pdf / .txt / .md，点「AI 解析试卷」自动识别题目、客观题答案与主观题得分点，填入后可手动修改

② 试卷题目

  • 客观题（选择/填空/判断）：标出标准答案，本地精确比对自动判分，不消耗 token
  • 主观题（简答/计算/论述）：由 AI 按参考答案 + 得分点评分

③ 学生答卷（减少信息录入）

  • 📷 「批量上传答卷图片」：一次选择多张，AI 视觉识别姓名/考号与逐题答案自动填入
  • 「从剪贴板批量导入」：粘贴文本批量导入（首行姓名/考号）
  • 学生姓名/考号选填，软件自动识别并用于成绩对应与导出

④ 开始整卷阅卷：客观题自动比对、主观题 AI 评分，自动汇总成绩（导出按姓名/考号对应）

4. 📊 学情分析

自动聚合失分点，生成成绩分布与学情报告，辅助教学改进，支持导出报告。

五、AI 服务配置

在「设置」中配置 AI 服务，支持：

  • API 地址：填写服务商接口地址

六、数据与隐私

  • 所有阅卷记录、模板、密钥均保存在本机浏览器存储中

七、常见问题（FAQ）

Q1：试卷上传支持哪些格式？
支持 .docx、.pdf、.txt、.md。仅支持「文字版」文件；扫描图片型 PDF 需先 OCR；.doc 旧格式需另存为 .docx。

Q2：客观题如何自动批改？
客观题填入标准答案后，软件本地归一化（去空格/标点/大小写）精确比对，秒出结果，不消耗 token。目前为严格比对（多选需顺序一致），判分后可在成绩里手动微调。

Q3：学生信息怎么填写？
无需逐一录入。答卷图片导入时 AI 会自动识别答卷上的姓名与考号；文本粘贴导入时首行写姓名/考号即可。请在答卷上写清姓名或考号，导出成绩时会按姓名/考号对应。

Q4：答卷图片识别准确吗？
AI 视觉识别手写答卷可能存在误差，识别后建议老师快速核对一遍再确认。

Q5：换电脑后激活码还能用吗？
解锁串与机器码绑定，换电脑需重新获取解锁串；重装系统导致机器码变化，也需重新获取。

Q6：软件如何更新？
软件启动后自动静默检查更新，发现新版会提示下载；也可在「设置 → 关于与更新」手动检查。左下角会显示当前版本号。

Q7：数据安全吗？
数据保存在本机，软件无后端服务器，不上传你的阅卷数据。
